# WeatherWise Dashboard

## About
WeatherWise is a simple weather dashboard that shows live weather using the Open-Meteo API.

## Features
- Search weather
- Live temperature and wind speed
- Loading and error handling
- Responsive design

## Technologies
- HTML
- CSS
- JavaScript
- Open-Meteo API
